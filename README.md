# DentaNote

> **Rascunho em construção.** Este README é atualizado a cada fase (ver `docs/AGILE.md`).

Assistente **100% local** de evolução clínica odontológica: o dentista grava (ou cola)
a consulta, um pipeline offline transcreve com Whisper, extrai os dados clínicos com
um LLM local (Gemma via Ollama) e redige um **rascunho de evolução clínica** pronto
para revisão.
